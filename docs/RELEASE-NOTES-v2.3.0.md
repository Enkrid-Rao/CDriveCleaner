# CDriveCleaner v2.3.0

> 冷数据归档改成「剪切」语义：不再有「链接归档」，源位置不留任何链接。

## 归档 = 剪切

- 归档方式只剩两种：**移动归档**（默认）和 **仅复制**；「链接归档」已移除。
- **移动归档**：复制 → 逐文件校验 → 清空源目录内容。源位置不再出现 Junction，
  等同手动剪切 + 粘贴。
- 新增设置 **「归档后保留原目录」**（默认开启）：开启时只清空内容、保留目录骨架；
  关掉后连源目录本身一起删除，与剪切 + 粘贴完全一致。
- 只有**本身已经是 Junction** 的目录（之前用「C 盘瘦身」迁过的应用数据）才会改指链接目标——
  这种情况删掉链接会让原路径消失、依赖它的程序直接坏掉。
- 兜底：对普通目录使用 link 模式的调用会被 `preflight_archive` 直接拒绝，CLI / 脚本也绕不过。

## 为什么要改

v2.0–v2.2 的「链接归档」会把源目录原地换成指向归档盘的 Junction。归档到 U 盘/机械盘以后，
**所有新产生的文件也会写到那块盘上**，拔盘后源路径直接不可用。这不是「把暂时不用的数据挪走」，
而是把整条路径托管给外置盘。

## 冷数据判级的修正

- 整个 `Downloads` 不再被判为「推荐归档」：它是浏览器与下载器的默认保存位置，
  现在最高只到「可选」，并提示只归档其中的子目录（Software / ISOs / Compressed 等）。
- 该判据提前到「视频 / 镜像 / 安装包」之前——否则 Downloads 因为塞满安装包会被判成
  STRONG 88，被整目录归档。

## 同时包含（v2.2.0 之后未发布的修复）

- 系统深色模式下「选择要归档的目录」对话框黑底黑字不可读：应用启动即钉死浅色配色。
- 该对话框补齐主题样式、改为中文文案（当前位置 / 目录 / 添加选中 / 取消）。
- 该对话框确认时不再「进入目录」，多选目录能正确返回结果。
- 侧栏条目宽度按最长项自适应，不再显示成 "My Com…"。

## 兼容性

- 老配置里的 `default_mode: "link"` 自动归一为「移动归档」。
- 旧版本留下的 Junction 不受影响：仍可在「链接管理」里查看、撤销或改指。
- 卸载/覆盖安装不影响 `%LOCALAPPDATA%\CDriveCleaner\` 里的配置与审计记录。

v2.2.0 及以上可以在应用内自动更新（设置 → 自动检查更新）。
