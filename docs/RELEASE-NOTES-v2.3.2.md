# CDriveCleaner v2.3.2

> 归档路径终于可配：**保留原路径**（`E:\C\Users\你\Downloads`）或**按目录名**（`E:\Downloads`）；
> 「归档后保留原目录」开关也搬到了归档页。

## 归档目录结构（新增）

设置页与「冷数据归档」页都能改，默认 **保留原路径**：

| 选项 | 结果 |
|---|---|
| 保留原路径 | `E:\C\Users\你\Downloads\Software`、`E:\D\Projects\Foo` —— 盘符 + 归档前完整路径 |
| 按目录名 | `E:\Downloads\Software`、`E:\Foo` —— 只按目录名同级摆放 |

- 候选列表、执行计划、确认框里的目标路径会实时跟着换算
- 老配置没有这一项时按「保留原路径」处理，也就是 v2.0 时代的结构
- 路径换算统一收口到 `models.archive_dest()`，扫描器、归档页、自定义目录不再各算各的

## 归档后保留原目录（位置修正）

这个开关 v2.3.0 就有，但只在设置页；现在「冷数据归档」页也放了同一个开关（两边双向同步）：

- 开：只清空内容、保留目录骨架，源目录仍然存在
- 关：连源目录本身一起删除，等同剪切 + 粘贴
