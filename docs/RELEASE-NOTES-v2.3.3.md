# CDriveCleaner v2.3.3

> 自动更新终于能真正装上了：下载包会自动走本机代理并在多条线路间重试。

## 为什么之前只能“检查”不能更新

- 检查更新走 `api.github.com`，直连通常没问题，所以总能发现新版本。
- 下载更新包会跳到 `release-assets.githubusercontent.com`，这个域名在部分网络下**直连必被 reset**。
- 旧版下载器用的是裸 `urllib`，没有任何代理支持，于是永远下不下来；表现就是「能检查到新版本，
  一点下载就失败」。安装脚本本身是好的，问题全在下载。

## 修复

- 下载按「**上次成功的代理 → 环境变量代理 → 本机常见代理（7899 / 7898 / 7890 / 10809 / 1080）
  → 直连**」依次尝试，失败换下一条，整体重试两轮。
- 成功的线路记到 `state/cache/update.json`，下次第一个就用它，不再每次先卡在直连上。
- 检查更新也有同样的回退链（直连优先，再走代理）。
- 对话框会显示实际线路：「下载完成（经 http://127.0.0.1:7899），SHA256 校验通过」；
  按钮文案改为「下载并安装」→「安装并重启」。
- 「稍后 / ✕」不再把这个版本永久标记为跳过（以前点一次就再也不会收到提醒）。

## 验证

- 用程序自己的 `download_asset()` 实测下载 v2.3.2 安装包：35.9 MB / 20.5 s / 1.8 MB/s，
  SHA256 通过，自动选中 7899 并记住线路。
- 更新安装脚本实测：等待主进程退出 → 运行安装包 → 重启新版本，全流程通过。
- 55 项单元测试通过（新增：线路优先级、本地 HTTP 下载、缺 digest 拒绝、检查线路顺序）。

## 升级

v2.2.0 及以上可以在应用内自动更新（设置 → 自动检查更新）；v2.1.0 及更早需要手动安装一次。
装到 v2.3.3 之后，下一次更新就能在应用里一键完成。
