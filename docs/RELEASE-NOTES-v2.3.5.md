# CDriveCleaner v2.3.5

> 归档现在可以**一键复原**；复制/校验的进度与剩余时间不再骗人；Temp 清理有反馈了。

## 新增：从归档目录复原

「操作记录」页右上角新增 **「从归档目录复原」**：

1. 选一个归档目录（例如 `E:\D\Projects\Sill-Promo`、`E:\C\Users\raoxi\.lmstudio`）
2. 自动反推原路径：
   - 优先读归档目录里的 `.cdc-origin.json`（每次归档都会写，任何目录结构都适用，自定义路径也能复原）；
   - 没有标记时按「保留原路径」结构推断：`E:\C\Users\...` → `C:\Users\...`，`E:\D\...` → `D:\...`
3. 确认后复制回原位置 → 逐文件校验 → **只有校验通过才删除归档副本**；原路径已有数据不会覆盖。

这样微信聊天记录、模型、采集文件这类「以后可能还要用」的冷数据，也可以放心归档了。

## 修复：进度与剩余时间

- 复制速度改用**最近 15 秒增量**计算。旧算法用「目标目录已完成量 ÷ 全程耗时」，
  目标里如果有上一次的旧副本，开头就会算得飞快，ETA 显示成 1 秒。
- **校验阶段现在也上报进度与剩余时间**（已校验 X/Y 个文件）。此前复制完成后界面停在 62%/69%，
  实际是在逐文件比对，什么都没显示，看起来像卡死。
- ETA 归零时显示「剩余 —」，不再保留上一阶段的旧数字。

## 修复：Temp 清理没反应

- 正在执行其它操作时点击清理会静默失败（`start_operation` 返回 False 但没有提示），现在会 toast 提示。
- 顶部建议区新增「**全部清理**」，不再只清 1 天前的文件。
- 清理完成后报告实际释放量；释放 0 B 时明确说明「都还在保留期内」。

## 验证

- 61 项单元测试通过（新增：来源标记反推原路径 ×3、按归档目录复原全流程、校验阶段必须上报进度）
- 本机实测：当前归档任务在 2.3.3 上会停在校验阶段的 62%；2.3.5 会持续显示校验进度
