# CDriveCleaner v2.3.6

> 归档确认窗口现在有三个勾选项：**压缩成 zip / 归档后校验 / 归档后删除原目录**。

## 新增：确认归档弹窗提供三项选择

点「开始归档」时的确认窗口，现在会带上与本次操作相关的可选项（默认值来自设置页，选择会被记住）：

| 选项 | 默认 | 说明 |
|---|---|---|
| **压缩成 zip 后归档** | 设置页决定 | 归档目录里生成 `<名称>.zip`，压缩包校验通过后才清空源目录。适合大量小文件、外置机械盘；仅「移动归档」且非 Junction 源可用 |
| **归档后校验副本** | 开 | 复制后遍历目标目录，逐文件比对数量和大小（不读文件内容）。关闭可明显加快，但不再逐文件比对 |
| **归档后删除原目录** | 跟随「归档后保留原目录」设置 | 勾选则连目录本身一起删掉，不保留空目录；只影响本次操作 |

- 关闭校验时，审计记录会标记「未校验」，完成提示也会提醒——因为跳过校验后仍会清空源目录。
- 设置页新增「默认校验副本」「默认压缩归档」两个开关。

## 新增：从归档目录复原

「操作记录」页右上角「从归档目录复原」：选一个归档目录，按 `.cdc-origin.json` 来源标记反推
原路径（没有标记时按「保留原路径」结构推断），复制回原位置、校验通过后才删除归档副本。
压缩归档（zip）也能识别并自动解压回原位置。

## 修复

- **复制速度改用最近 15 秒增量**：目标里已有旧副本时不再把 ETA 算成 1 秒。
- **校验阶段上报进度与剩余时间**：不再停在 62%/69% 让人以为卡死。
- ETA 归零时显示「剩余 —」。
- **Temp 清理**：忙时给出提示；新增「全部清理」；完成后报告实际释放量，0 B 时说明原因。

## 验证

- 66 项单元测试通过（新增：zip 归档 + 复原、跳过校验、删除源目录选项、多勾选项确认框）
- 压缩归档在测试里跑通「压缩 → 校验 → 清空源 → 复原解压 → 删归档」全流程
