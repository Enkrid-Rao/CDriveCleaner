# CDriveCleaner v2.3.7

> 目录选择器重做：左侧快速访问 + 磁盘、卡片式界面、自绘勾选框、默认回到上次浏览的目录。

## 目录选择器

此前选择目录是一个「路径栏 + 裸树」的朴素界面，而且每次固定从归档盘 `E:\` 开始，
看起来像“只能选这几个”。

现在：

- **左侧导航**：快速访问（用户目录 / 桌面 / 下载 / 文档 / 归档盘）+「磁盘」列表
  （C: / D: / E:，悬停显示可用空间）
- **右侧**：上一级 + 路径栏（可粘贴路径回车直达）+ 目录树
- **卡片式弹窗**：与应用其它对话框一致（圆角、投影、主题色）
- **目录树**：32px 行高、文件夹图标、悬停高亮；Junction 用链接图标 + `→` 标注，
  可展开浏览目标内容；隐藏目录灰色；无权限目录给提示行
- **自绘勾选框**：选中为品牌红底 + 白色对勾，底部实时显示「已选 N 项」，
  按钮变为「添加选中（N）」
- **双击展开**：折叠/展开切换，子目录在首次展开时才扫描加载
- **记住位置**：打开时回到上次浏览/确认过的目录；自定义归档入口默认从用户目录开始，
  复原入口默认停在归档盘

## 验证

- 66 项单元测试通过（选择器：隐藏目录与 Junction 可列出并展开、勾选结果、多选项确认框）
- 实测：双击展开 → 懒加载子目录（3 项），再次双击收起；勾选与展开互不干扰
