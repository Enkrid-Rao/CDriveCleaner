# CDriveCleaner v2.3.8

> 接入 Everything 索引：冷数据分析更快，总览页新增「空间构成 · 最大文件 Top 25」。

## Everything 加速

检测到本机装有 Everything（`es.exe`，可在 PATH 或注册表安装路径找到）且索引已加载时：

- **冷数据分析**改用 Everything 的 NTFS 索引统计每个目录的文件数、体积、扩展名构成、
  最新修改时间，不再逐个 `os.scandir` 遍历；USB / 机械盘上尤其明显。
- **失败自动回退**：没装 Everything、没运行、索引未加载、目录不在索引里、查询超时，
  都会退回原来的逐文件遍历，结果不受影响。
- 设置 → 冷数据归档 → **「用 Everything 加速分析」** 可关闭。

## 总览页新卡片：空间构成

- 秒级列出全盘最大的 25 个文件（大小 + 路径 + 打开所在目录）
- 首次进入总览页自动查询一次，「重新扫描」可手动刷新
- 未检测到 Everything 时显示提示（按钮置灰），不会报错
- 归档复制、校验、复原**仍然全部以真实文件系统为准**，不使用索引

## 验证

- 新增 `tests/test_everything.py`（解析千分位大小 / ISO 与斜杠日期 / 目录行过滤 /
  按一级目录聚合 / 可用性禁用），全部通过
- 扫描器新增索引优先测试：Everything 可用时直接用索引统计
- 总览页新增卡片测试：Everything 不可用时按钮置灰并给出提示
- 真实环境实测：`D:\Projects`（12.3 万文件）索引统计约 15 秒完成分析（含 Junction 与二级展开）
