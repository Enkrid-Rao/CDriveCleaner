# CDriveCleaner v2.3.9

> 目录选择器补齐键盘多选：Ctrl+A 全选、空格勾选、Ctrl+点击切换、Shift 连选，勾选跨目录保留。

## 目录选择器：多选体验补齐

上一版换了新界面，但少了文件管理器里习惯的键盘操作，选多个分散的小目录很繁琐。现在补上：

| 操作 | 效果 |
|---|---|
| **Ctrl+A** | 勾选当前列表里的全部目录（含已展开的子项） |
| **Ctrl+Shift+A** | 清空全部勾选 |
| **空格** | 切换当前高亮目录的勾选 |
| **Ctrl+点击** | 单项切换勾选（与点勾选框等价） |
| **Shift+点击** | 从上次点击项连选到这一项 |
| **全选 / 反选 / 清空** | 树上方的三个按钮，鼠标也能用 |

### 勾选不再随目录切换丢失

之前换一个目录，前面勾的就没了——这是「选多个小目录很繁琐」的根因。现在勾选状态保存在
选择器内部的选择表里：

- 在 `D:\A` 勾几个 → 切到 `D:\B` 勾几个 → 切回 `D:\A`，之前的勾选仍然在
- 底部「已选 N 项」和「添加选中（N）」实时显示总数
- 确认后按勾选顺序一次性返回全部目录

## 其他
